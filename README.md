# Tâches du jour

Petite application web pour cocher depuis son téléphone les tâches à faire chaque jour.

- La liste se remet à zéro chaque jour. L'historique est conservé.
- Appuyer sur une tâche la valide (l'heure est notée). Appuyer de nouveau l'annule.
- « Modifier la liste » : ajouter, renommer, réordonner ou supprimer des tâches.
- Série de jours consécutifs où tout est fait, et calendrier des 30 derniers jours.
- Fonctionne hors connexion et s'installe sur l'écran d'accueil.
- Les données restent sur le téléphone (stockage du navigateur). « Exporter » / « Importer » permettent de les sauvegarder ou de les transférer.

## Mise en ligne avec GitHub Pages

1. Sur GitHub, ouvrir le dépôt → **Settings** → **Pages**.
2. Dans **Build and deployment**, choisir **Deploy from a branch**, sélectionner la branche qui contient ces fichiers et le dossier `/ (root)`, puis **Save**.
3. Après une minute, l'adresse s'affiche (du type `https://<utilisateur>.github.io/<depot>/`).

## Installer sur le téléphone

- **iPhone (Safari)** : ouvrir l'adresse → bouton Partager → « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir l'adresse → menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».
